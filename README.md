# She&Me — сайт сухого гель-шампуня

Статический сайт: `index.html` + `styles.css` + папка `assets/`. Сборка не нужна, Vercel подхватит сам.

## Как обновить сайт
1. В репозитории замените `index.html` и `styles.css` файлами из этого пакета.
2. В папку `assets/` добавьте новые файлы (`step-1.jpg` … `step-4.jpg`, `texture.jpg`, `bag.jpg`, `aerosol.jpg`, `gel-apply.jpg`).
   Уже существующие `logo-original.png`, `model.webp`, `tube.png`, `sachet.png` не трогайте.
3. Commit → push. Vercel опубликует новую версию автоматически.

## Важно про картинки
Новые картинки в `assets/` вырезаны из рендера, поэтому они небольшие и могут выглядеть мягкими. 
Чтобы получить максимальное сходство с рендером, замените их оригиналами **под теми же именами**:
- `step-1.jpg … step-4.jpg` — кадры шагов (пальцы с гелем, нанесение, массаж, результат), ~800×600
- `texture.jpg` — мазок геля на тёмном фоне
- `bag.jpg` — сумка с тубой, вертикальный кадр
- `aerosol.jpg`, `gel-apply.jpg` — сравнение аэрозоль / гель, ~800×600
- `model.webp` — главное фото модели (широкое, лицо по центру), от 1600 px по ширине
