# She&Me — версия с реальными фотографиями

Готовый статический сайт для GitHub + Vercel.

## Публикация
Загрузите в корень репозитория **все файлы и папку `assets`**, сохраняя структуру. Старые `style.css` и `README.txt` не нужны. Vercel: Framework Preset = Other, Output Directory = пусто.

## Что добавлено
- Оригинальный логотип бренда в шапке и подвале.
- Реальные фотографии тубы 80 мл и саше 5 мл (оптимизированы в WebP без ретуши).
- Блок двух форматов и пояснение о ручной клади.
- SEO-метаданные и изображения продукта в Schema.org.

## Перед запуском продаж
Замените контактный email, если он не действующий, и добавьте подтверждённые цены и ссылки на карточки маркетплейсов. Уточните правила перевозки жидкостей у перевозчика.
