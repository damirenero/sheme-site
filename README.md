# She&Me — статический лендинг

Готовый сайт для GitHub и Vercel. Без npm и сборки.

## Деплой
1. Создайте новый репозиторий GitHub или загрузите файлы в корень существующего репозитория.
2. Загрузите `index.html`, `styles.css`, `script.js` в одну папку (корень репозитория).
3. Vercel → Add New → Project → Import Git Repository.
4. Framework Preset: Other; Root Directory: `./`; Build Command: пусто; Output Directory: пусто.
5. Deploy. Следующие коммиты будут обновлять сайт автоматически.

## Перед запуском продаж
- Замените CSS-иллюстрацию флакона настоящей фотографией продукта.
- В `index.html` укажите реальные ссылки на карточки Ozon/Wildberries после их создания.
- Добавьте проверенные отзывы, цену и характеристики, если они подтверждены.
- Сейчас CTA «Уточнить наличие» открывает письмо на sheandme@yandex.ru; серверной формы нет.

Внимание: если текущий проект Vercel подключён к другому репозиторию, новый репозиторий сам по себе не заменит старый деплой — подключите новый проект или измените привязку Git в Vercel.
