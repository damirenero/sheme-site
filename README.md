# She&Me — сайт для GitHub и Vercel

Статический лендинг без сборки. Содержит реальные фотографии товара с удалённым фоном, оригинальный логотип, изображение модели, адаптивный дизайн, SEO-метатеги, FAQ и ссылку на карточку 80 мл на Ozon.

## Публикация

Загрузите содержимое папки (index.html, styles.css, script.js, robots.txt, sitemap.xml и папку assets) в корень репозитория damirenero/sheme-site, заменяя одноимённые файлы. Vercel автоматически развернёт сайт из main, если Git-интеграция настроена.

## Важно

Фото упаковок получены из предоставленных снимков с программным удалением фона. Проверьте края объектов перед публикацией. Ссылка Ozon ведёт на предоставленную пользователем карточку 80 мл. Для саше отдельной ссылки на покупку нет. Сведения о перевозке в ручной клади зависят от правил перевозчика.
